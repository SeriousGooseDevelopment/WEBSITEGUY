# WEBSITEGUY

Static build of the Timothy product-designer site, served at https://timthewebsiteguy.com (Cloudflare Pages project `tim-the-website-guy`).

- `index.html`, `_next/`, `assets/`, `projects/`, `fonts/`, `cursors/`, `og.png` are the deployed files.
- Deploy: `wrangler pages deploy . --project-name tim-the-website-guy --branch main`
- Captured from the live seriousgoosestudios.com build (original source was not available); og tags point at timthewebsiteguy.com.
